# Digital Gardens North Tyne — research release V31 (10 November 2026)

## Contents and study scope
This research archive accompanies the *Energy & Environmental Science* Analysis manuscript, **Digital Gardens of North Tyne versus grid-supplied AI campuses: energy, carbon, heat, computing and community benefits**. It contains the same physical case, datasets, figures, optimisation model and supporting scenario programmes. No patent applications are pending in this project.

The corrected 4–5 MW generic power curve and 12% combined wind losses are used in all central-year and year-paired dispatch comparisons. The selected 80% hourly renewable self-supply target gives 400 MW onshore wind, 800 MWp solar and 100 MWh/25 MW storage, and a model energy cost of ~£101.1/MWh. These are conditional optimisation results rather than commissioned wind farm, solar park, power system, network tariff, or hardware performance measurements.

## Reproduction from prepared inputs
From this directory in Python 3.10+ with `numpy`, `pandas`, `matplotlib`, and `python-docx` installed:

```
python power_247.py design
python design_trajectory.py
python heat_community.py
python island_network.py
python export_scenarios.py
python design_econ.py
python revised_sensitivities.py
python pv_lca_screen.py
python turbine_trip_screen.py
python validate.py
```

The **149 assertions in validate.py** were executed and passed after the generator-trip and community-tier adjustments. The full original power_247.py, 25-year scenario and additional program scripts can be run as documented in README.md if reproducing every other output. The curated Article.docx, Supplement.docx and Cover.docx are final editorial artifacts and are NOT regenerated byte-for-byte by the historical `build_manuscript.py` draft generator. Numerical figure regeneration is via `figures.py` for original Figures 1–8 and `turbine_trip_screen.py` for Figure 9.

Key output files: `OUTPUT/island_network.json` (power-limited 25 MW battery), `OUTPUT/TURBINE_N1_POWER_LIMIT.csv` (loss-of-unit hourly trace), `OUTPUT/PV_LCA_SCREEN.csv/.json` (35 vs 48 g/kWh lifecycle sensitivity), `OUTPUT/heat_community.json` (free vehicles tier B), and `OUTPUT/design_econ.json` (economic comparison). The proposed 13,159-vehicle programme is funding/uptake dependent; at assumed 8–12 t CO2e each over 12 years its own manufacturing accounts for 8.8–13.2 kt/year and lowers the 16.9 kt/year gross avoided result to 3.7–8.1 kt/year before a marginal manufacturing baseline. The tier-weighted modelled gross community avoided emissions are ~58.2 kt/year, or ~51.7–53.8 kt/year after the specified manufacturing allowance.

Raw site-specific wind-farm generation, electricity grid access/contract tariffs, local river flow-temperature observations, and real Spectrum-XGS node-to-node GPU benchmarks remain unverified. The numerical model does not establish islanded N-1 continuity (21.8 MW immediate shedding upon loss of one 55 MW unit under full load).
